## ppp-secret [27, 101] — 40 rows
- `0x1` str = name ✅ (sesuai verifikasi CRUD sebelumnya)

## Interface detail [20,0] — DITAMBAHKAN 2026-10-16, DIVERIFIKASI 2026-10-17

Key berikut dari parse `roteros.jg`, DIVERIFIKASI via dump live v6+v7 2026-10-17:
- `0x404` (raw 6 byte) = MAC Address — ⚠️ `.jg` bilang `0x26D`, SALAH (0 baris di live)
- `0x10064` (u32) = MTU ✅ cocok .jg
- `0x10065` (u32) = L2MTU
- `0x3F2` (u8 enum) = Speed — 2≈1G, 3≈10G/SFP+ (bukan bps)
- `0x1000E` (bool) = Running
- `0x7D1` (u8/u32) = VLAN ID, `0x7D2` (u8) = parent interface itemId
- `0x100D4` (q100d4, bigbitrate, ro) = Tx rate
- `0x100D3` (q100d3, bigbitrate, ro) = Rx rate
- `0x100FD`/`0x100FC` (bigbytes) = Tx/Rx Bytes
