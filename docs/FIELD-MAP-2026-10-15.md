# Field Map — live dump 2026-10-15

Sumber: dump `getAllRows` langsung dari router produksi juragan (RB750Gr3)
via WinBox protocol. Nilai sensitif (password, nama user) TIDAK dicatat di sini —
hanya struktur field + temuan semantik. Raw dump hanya ada di /tmp (ephemeral).

## ppp-secret [27, 101] — 40 rows
- `0x1` str = name ✅ (sesuai verifikasi CRUD sebelumnya)
- `0x2` str = password ✅ (ada, bisa dibaca — syarat juragan terpenuhi)
- `0x3` u8 = service numeric (teramati: 3 = PPPoE di semua secret aktif)
- `0x5` u8 = profile numeric (bervariasi per secret)
- `0xf` str = caller-id / MAC
- `0x6f` bool = disabled ✅
- `0xfe0001` = row id (wajib untuk SET/REMOVE)
- `0xfe0009` str = comment
- Field lain: 0x4,0x6,0x7,0x8,0x9,0xa,0xc,0xd,0xe,0x10,0x6a,0x6b,0xfe000a,0xfe0012

## ppp-profile [27, 102] — 7 rows
- `0xfe0009` str = name
- u32 `0x17,0x18,0x19,0x1c,0x1f` = rate-limit family
- str `0xe,0xf,0x10,0x11,0x16,0x21,0x33,0x34,0x36` = address/bridge/queue fields
- Banyak bool 0x66..0x8d = opsi profile

## ppp-active [27, 103] — 27 rows
- `0xfe0009` str = name
- `0x3` str = caller-id (format MAC "XX:XX:XX:XX:XX:XX")
- `0x9,0xa` u64 = bytes (up/down) — 0 di sampel = sesi idle/stale
- `0xb` u32, `0x6` u8, `0x7` u32 = session/service info (belum dipetakan)
- `0xfe0001` = row id

## firewall-filter [20, 3] — 22 rows
- `0x28` u8 = action (teramati: 10)
- `0x5a` str, `0xd6` bool, `0x1b4` bool = matcher fields
- `0x2710,0x2711` u64 = packets, bytes (perlu stats bit 0x2 di flag getall)
- `0xfe0009` = comment, `0xfe000a` = disabled
- `0xff0010` u8 = order/position
